# DevAngular333 portfolio

Static portfolio for [DevAngular333](https://github.com/DevAngular333): a
Code2Flow Review Pack demo, public products, their evidence, and the limits of
each claim.

The deployed page is generated from `index.html` and contains no runtime data,
credentials, analytics, or external API calls.

The `review-pack-demo.html` artifact is generated from the labeled synthetic CRM
revision pair in the Code2Flow release. It stores review notes only in the
browser's local storage and exports JSON; it does not call a backend.

The Agent Teacher card points to the license-correction patch release
[`v0.1.1-devangular333`](https://github.com/DevAngular333/design-os-pedagogy/releases/tag/v0.1.1-devangular333); the earlier `v0.1.0-devangular333` tag remains unchanged.

The `assets/` directory contains screenshots captured from released local
flows: the Review Pack public demo, Agent Teacher UI, Code2Flow viewer export,
and InkOS bridge smoke evidence card. They are evidence images, not product
mockups.

Live page: <https://devangular333.github.io/devangular333-portfolio/>
