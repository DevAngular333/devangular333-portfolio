# DevAngular333 portfolio

Static portfolio for [DevAngular333](https://github.com/DevAngular333): three
public products, their evidence, and the limits of each claim.

The deployed page is generated from `index.html` and contains no runtime data,
credentials, analytics, or external API calls.

The `assets/` directory contains screenshots captured from the released local
flows: the Agent Teacher UI, the Code2Flow viewer export, and the InkOS bridge
smoke evidence card. They are evidence images, not product mockups.

Live page: <https://devangular333.github.io/devangular333-portfolio/>
